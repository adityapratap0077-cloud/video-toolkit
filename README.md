## What this is

The AI video and audio production skills I use for promos, explainers, and content. No code copied here, only links to the originals plus notes on when each one earns its place.

## What's inside

| Tool | What it does | Link | License | My note |
|------|--------------|------|---------|---------|
| brag / narrate | Launch videos and narrated demos | bundled with my agent environment | check upstream | Turn a shipped project into a shareable video. Great for launches. |
| flick | Short-form scene animation from video or transcript | bundled with my agent environment | check upstream | For turning existing footage into animated shorts. |
| lean-video | Low-cost promo and explainer video builds | bundled with my agent environment | check upstream | When the budget is tokens, not dollars. Say "keep it lean". |
| video-shotcraft | Video shot planning | [Vincentwei1021/video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft) | Apache | Plan the shots before rendering anything. |
| vox-animation | Voiceover animation | bundled with my agent environment | check upstream | For animation timed to narration. |
| downthegroup | Hindi/Hinglish documentary video pipeline | bundled with my agent environment | check upstream | Full pipeline: research, script, voiceover, visuals. My pick for Hindi content. |
| heygen-skills | HeyGen avatar, video generation, translation | [heygen-com/skills](https://github.com/heygen-com/skills) | MIT | Avatars, presenter videos, dubbing. The face-and-voice toolkit. |

## How I use these

Promo for a shipped product: brag. Explainer on a budget: lean-video. Hindi documentary: downthegroup end to end. Need a presenter who is not me: heygen-skills. Shot planning always comes before rendering.

## How to use this list

Pick the tool that matches your problem, follow its link, install it per its own README. Star the ones you keep coming back to.
